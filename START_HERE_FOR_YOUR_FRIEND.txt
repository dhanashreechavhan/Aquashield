AQUASHIELD: START HERE

1. Download the ZIP and extract it first. Do not run the app from inside the ZIP. Open the extracted folder that contains start_aquashield.bat, src, data and models.
2. Install Python 3.10 or newer from python.org. On the installer screen, enable the option to add Python to PATH if it is shown.
3. In VS Code, use File > Open Folder and open that extracted project folder. In the Explorer, check that src, data and models are visible.
4. Double-click start_aquashield.bat.
5. On the first run, wait while it creates a private Python environment and downloads the required packages. An internet connection is needed for this setup.
6. When the app starts, open http://localhost:8501 in a browser if it did not open automatically.
7. Keep the black terminal window open while using the app. Close that window when finished.

WHAT IS INCLUDED
- Streamlit app and its data files
- Saved ML model files and measured proxy-label evaluation metrics
- Public YouTube and manually catalogued Instagram demo records
- Project setup notes and AquaShield_Project_Explained.pdf
- Dark theme, dark charts and dark map tiles

PLEASE SAY THIS HONESTLY IN THE PRESENTATION
- ML labels are generated by a rule; scores are not proven real-world flood accuracy.
- IoT readings are simulated; no ESP32/Firebase hardware is connected.
- Safe Routes is a road-midpoint demo approximation, not turn-by-turn navigation.
- Instagram records are manually catalogued. Social-media locations/severity are unverified.
- Reports are saved locally on the computer running the app.
- The YouTube list is a saved catalog, not a continuously updated/live feed; Instagram cards are demos, not live posts.
- A public deployment is a demonstration only. Community submissions are unverified and cloud-local storage may reset.

TROUBLESHOOTING
- If Windows says Python is not found, install Python, restart the computer, and try again.
- If the first setup fails, check the internet connection and try double-clicking start_aquashield.bat again.
- If the browser says the page cannot be reached, check that the black terminal window is still open and read the error shown there.
- If port 8501 is already in use, close any other AquaShield/Streamlit terminal and try again.
